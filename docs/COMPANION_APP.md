# BMO Companion App

Purpose

The Companion App acts as BMO's brain.

The ESP32 is responsible for:
- Display
- Touch
- Buttons
- LEDs
- Speaker
- Animations

The PC is responsible for:
- AI
- Speech Recognition
- Text To Speech
- Weather
- Spotify
- ToDo Lists
- Notifications
- Calendar Integration

Communication

ESP32 <-> USB Serial <-> Python App

Future:
ESP32 <-> WiFi <-> Python App
